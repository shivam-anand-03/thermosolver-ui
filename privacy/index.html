Privacy policy

Effective 4 November 2026

The short version

CFD Solver has no accounts, sets no cookies, and runs no analytics or advertising trackers.

What is sent to the API

When you solve, validate or export, the numbers that describe your problem (geometry, grid, material properties, boundary conditions and solver settings) are sent to the CFD Solver API. The API computes the answer and returns it. It does not save your problem. If a request causes an unexpected error, the error is written to the server log so it can be fixed.

What is saved in your browser

The solver keeps your current set-up in your browser's local storage under the key thermosolve.workflow.setup.v1, so it survives a page reload. It never leaves your device. Use Reset in the app or clear your browser's site data to remove it.

Third parties

The website is hosted on Vercel and the API on Render. Like any web host, they process standard request data such as IP address, time and requested URL under their own privacy policies. Fonts load from Google Fonts and the maths renderer on the home page loads from cdnjs (Cloudflare), so those services also see your IP address when the page loads.

Children

CFD Solver does not knowingly collect personal information from anyone, including children.

Changes and contact

This policy may be updated; the date above shows the latest version. Questions go to the project's GitHub issues.
