# ThermoSolve UI — `thermosolver-ui`

The web front end for **ThermoSolve**, an educational numerical solver for one-dimensional heat conduction in a plane slab. It walks you through setting up a steady or transient problem, sends it to the ThermoSolve API, and shows every intermediate quantity: Δx, each matrix row, each row operation and each back-substitution line.

Built with React 19, TypeScript, Vite 8, Tailwind CSS 4, Radix UI, Recharts and KaTeX.

The solver itself lives in a separate repository, [`thermosolver-server`](https://github.com/shivam-anand-03/thermosolver-server). This app does no numerical work; it needs a running API.

---

## 1. Features

| Area | What you get |
|---|---|
| Wizard | 7 steps: problem type → geometry → material → boundary conditions → numerical settings → review → results |
| Live preview | Slab diagram that updates as you type; edits after a solve re-run it automatically (debounced) |
| Results tabs | Overview · Step-by-Step · Matrix · Algorithm · Graph · Data · Validation |
| Transient | Animated temperature profile with playback controls, and a T–t chart for any selected node |
| Maths | Governing equations and FD stencils rendered with KaTeX |
| Examples | **Load Example** menu fed by the API, with printed reference values compared against computed ones |
| Export | CSV, JSON (configuration + full results) and the PDF report generated by the API |
| Units | m / cm / mm and °C / K on input; display unit switchable in the results view |

## 2. Quick start

Requirements: Node.js 20.19+ (22.x recommended), and the API running locally on port 8000 (see the `thermosolver-server` README).

```bash
npm install
npm run dev
```

Open **http://localhost:5173**. In development the Vite server proxies every `/api/...` request to `http://127.0.0.1:8000`, so no CORS setup is needed.

If the API isn't running you'll see *"Cannot reach the ThermoSolve API. Make sure the backend is running on port 8000."*

## 4. Configuration

Copy [.env.example](.env.example) to `.env.local` (already git-ignored) to override these:

| Variable | Used by | Meaning |
|---|---|---|
| `VITE_API_URL` | the built app | Base URL of the API, e.g. `https://thermosolve-api.onrender.com`. **No `/api` suffix** — the app adds `/api/...` itself. Leave empty in development to go through the proxy. |
| `VITE_PROXY_TARGET` | `npm run dev` only | Where the dev proxy sends `/api` requests. Default `http://127.0.0.1:8000`. |

`VITE_*` values are baked into the bundle at build time. Changing `VITE_API_URL` requires a rebuild (a redeploy on Vercel).

When the app is served from a different origin than the API, that origin must be listed in the server's `THERMOSOLVE_CORS_ORIGINS`.

## 5. How it talks to the API

All requests go through [src/lib/api.ts](src/lib/api.ts):

| Call | Endpoint |
|---|---|
| Load examples | `GET /api/examples` |
| Solve | `POST /api/solve/steady` or `POST /api/solve/transient` |
| Validate inputs | `POST /api/validate` |
| Download PDF report | `POST /api/report/pdf` |

API errors (HTTP 422 with `{success: false, error, details, kind}`) are shown in the UI as-is; network failures are reported as `kind: "network"`. Request and response types are in [src/types/solver.ts](src/types/solver.ts).

## 6. Project structure

```
src/
  main.tsx, App.tsx          entry point
  pages/SolverPage.tsx       the single page: wizard + results
  hooks/
    useSimulation.ts         form state, derived mesh values, debounced live re-solve
    usePlayback.ts           transient animation playback
  components/
    wizard/                  one component per wizard step (Problem, Geometry, Material, Boundary, Numerical, Review)
    results/                 results view and its tabs, matrix grid, charts, reference comparison
    diagram/SlabDiagram.tsx  live slab + boundary-condition diagram
    layout/                  header, stepper, signature
    math/Tex.tsx             KaTeX wrapper
    ui/                      shadcn-style primitives (button, card, tabs, slider, …)
  lib/
    api.ts                   API client
    form.ts                  form model, defaults, client-side validation, request building
    fd.ts, matrix.ts         finite-difference and matrix display helpers
    units.ts, format.ts      unit conversion and number formatting
    chart.ts, palette.ts     chart helpers and colours
    export.ts                CSV / JSON download
  types/solver.ts            API request/response types
public/                      logos, favicon, sample PDF report
```

The `@/` import alias maps to `src/` (see [vite.config.ts](vite.config.ts)).

## 7. Deployment

The app is deployed to Vercel as a static Vite site with this repository at the root:

| Setting | Value |
|---|---|

| Output Directory | `dist` |
| Node.js Version | 22.x |
| Environment | `VITE_API_URL=<API base URL>` |
