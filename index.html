Workflow

Preprocessor, solver, post-processor.

The same three phases as the course notes, eleven steps in all. Every step keeps a live diagram of the current set-up and the governing equation for the physics you chose.

1
Phase I
Preprocessor

Describe the physics, the domain and the conditions on it.

  1. IProblem statementConduction, convection–diffusion or convection · steady or unsteady · q‴ = q₀ + βT
  2. IIGeometry and gridL, W, H and Nx, Ny, Nz on a structured grid
  3. IIIPhysical phenomenaPrescribed velocity; Péclet, Fourier and Courant numbers
  4. IVMaterial propertiesk, ρ, cp for solids and fluids
  5. VInitial and boundary conditionsTemperature, heat flux, convective, insulated, inflow, outflow
2
Phase II
Solver

Choose how to discretise, how to invert, and when to stop.

  1. INumerical methodFDM with ghost nodes · FVM with upwind, central or hybrid faces · Galerkin FEM
  2. IIMatrix inversionGauss–Seidel / SOR, Gauss elimination with partial pivoting, LU (PA = LU). All hand-written
  3. IIIConvergence and initialisationTolerance, iteration cap, ω, initial guess, θ-scheme in time
  4. IVRun calculationCtrl + Enter from any step
3
Phase III
Post-processing

Read the answer, then check it against something exact.

  1. IResultsNode / x / T table, fields, profiles, monitor-point history, [A] and its LU factors
  2. IIValidationExact solutions, error norms, residuals, grid-convergence study with the observed order

Method

Watch the elimination, row by row.

This is the steady MST-1 example: a 0.5 m slab with five nodes, k = 1 W/m·K, 373 K on the left face and 1000 W/m² entering on the right. The walkthrough below runs the same algorithm as the API, written in plain JavaScript for this page.

Governing equation
d²T/dx² + q‴/k = 0
Central difference
d²T/dx²|ᵢ ≈ (Tᵢ₊₁ − 2Tᵢ + Tᵢ₋₁) / Δx²
Interior rows
−Tᵢ₋₁ + 2Tᵢ − Tᵢ₊₁ = (q‴/k)·Δx², i = 2 … N−1
Boundary rows
T₁ = 373, −T₄ + T₅ = q″Δx/k = 125
Linear system
[A]{T} = {b}, Δx = L/(N−1) = 0.125 m
Transient rows
−Fo·Tᵢ₋₁ⁿ⁺¹ + (1+2Fo)·Tᵢⁿ⁺¹ − Fo·Tᵢ₊₁ⁿ⁺¹ = Tᵢⁿ + Fo·(q‴/k)·Δx², Fo = αΔt/Δx²

Rows that already have a zero below the pivot are skipped, so a tridiagonal system costs O(N²) instead of O(N³). A thousand nodes solve in well under a second. The fully implicit scheme is unconditionally stable, so ThermoSolve never labels Fo > 0.5 as unstable.

Features

Built to be read, not just run.

Everything the solver computes is shown, in the order you would write it by hand.

Step-by-step derivation

Governing equation, stencil, boundary rows and the assembled system, rendered with KaTeX for the exact problem you entered.

Matrix and algorithm tabs

The augmented matrix [A | b], each pivot, each row swap, each row operation, the upper-triangular system and every back-substitution line.

Live slab preview

The diagram updates as you type. Edit any input after a solve and the result re-runs on its own, debounced.

Transient playback

Δt from a Fourier number or entered directly. Animated profile with playback controls and a T–t chart for any node you pick.

Validation

Residual max|A·T − b|, boundary residuals, energy balance, exact solutions where they exist, and a grid-convergence study with the observed order.

Reference examples

Load the MST-1 cases and course examples. Printed reference values sit next to computed ones with their differences, and never enter the solver.

Export

PDF report with derivation, matrices, elimination steps and charts. CSV for node data. JSON for the full configuration and results.

Units that match the course

m, cm, mm and °C, K on input. Switch the display unit in the results. SI internally, so the matrices look like hand calculations.

Validation

Reference values are compared, never copied.

API

The same solver, over HTTP.

A FastAPI service assembles the system, eliminates, and returns every intermediate quantity as JSON. The web app does no numerical work of its own. Interactive docs live at /docs.

  • GET/api/healthLiveness
  • GET/api/examplesExample catalogue with reference values
  • POST/api/solve/steadySolve a steady problem
  • POST/api/solve/transientSolve a transient problem
  • POST/api/validateValidate inputs without solving
  • POST/api/report/pdfPDF report: derivation, matrices, charts, validation
  • POST/api/v2/simulateThree-phase engine: FDM, FVM, FEM in 1-D, 2-D, 3-D
